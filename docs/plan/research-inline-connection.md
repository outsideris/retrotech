# 파일 HTML에서 추가 조사 연결 복구

## 원인과 변경

- 2026-09-24 확인: 49327의 로컬 서버가 실행 중이지 않았다. 기존 UI는 `file://`에서 연결을 시도하지 않고 다른 주소로 이동하도록 했다.
- 파일 HTML이 원래 문단과 사이드바를 유지한 채 고정된 loopback API에 요청한다. 보고서별 연결 토큰으로 파일 출처의 API 접근을 제한한다.
- 연결 상태·주기적 재시도·수동 재시도를 제공하고 끊긴 동안 전송을 막는다. 질문 초안과 읽던 위치는 보존한다.
- 실행기에서 `-open`을 제거해 새 브라우저 창을 열지 않는다. 서버가 종료되면 재실행해야 하는 실제 제약을 화면에 설명한다.

## 완료 기준

- [x] 파일 페이지에서 질문과 결과 저장이 동작하며 새 창·URL 이동이 없다.
- [x] 외부 웹 출처와 다른 보고서의 연결 정보로는 API를 호출할 수 없다.
- [x] 연결이 끊겼다 복구되어도 초안·원문·삽입 결과를 유지한다.
- [x] 현재 보고서와 실행 바이너리를 갱신하고 연결을 복구한다.

## 검증과 한계

Go 접근 검사와 Chrome 통합 검사로 확인한다. CLI 프롬프트·모델·조사 데이터는 변경하지 않는다. HTML만으로 로컬 CLI를 실행할 수 없으므로 사용 중 연결 프로그램이 필요하다. 새 포트를 배정받으면 업데이트된 HTML을 새로 고쳐야 한다.
