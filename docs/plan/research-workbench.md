# 문단에 연결된 추가 조사

## 요구와 결정

- 로컬 HTML의 주 스토리라인을 유지하며 우측 채팅에서 특정 장·문단의 추가 조사를 요청한다.
- 로컬 Codex/Claude Code CLI의 기존 로그인을 이용한다. 기본은 GPT-5.6 Sol/high, Claude Sonnet 5/high 및 복잡한 조사용 xhigh를 선택한다.
- 결과는 질문·시간·모델·출처와 함께 해당 문단 뒤에 자동 추가한다. 원문을 조용히 교체하지 않는다. 정정은 구분해 표시한다.
- 질문과 결과, 읽는 위치를 보존한다. 조사 실패·취소·재시작 후에도 기존 본문이 남는다.
- 추가 질문에서 도출한 일반적인 조사 규칙을 초안으로 모으고, 사용자가 정리해 선택한 규칙만 스킬에 반영한다.

## 구현

- `cmd/research`: loopback 전용 서버와 로컬 실행기. `internal/research`: 원문 보존, 문단 위치, 조사 이력·결과, HTML/Markdown 갱신, HTTP API.
- `internal/editor/assist/research.go`: 기존 CLI 탐색을 재사용하는 웹 조사 전용 호출. 구조화 결과를 반환하며 CLI가 직접 보고서를 편집하지 않는다.
- 기존 보고서 HTML/Markdown을 `.research`에 보존하고 추가 조사 상태에서 두 산출물을 재생성한다. 파일 직접 변경 충돌을 감지한다.
- 상태 변경 API는 같은 Origin·정해진 JSON 요청만 허용한다. 결과의 HTML은 서버가 escape하여 만든다.
- 저장된 HTML은 오프라인으로 읽을 수 있고, 추가 조사는 `start-research.command`로 로컬 서버를 열어 사용한다.
